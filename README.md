# Sipru.

Минималистичный редактор для писателей — бумага и чернила, швейцарская типографика, ноль отвлечений.

**→ [sipru. live]([https://dantemorrigan.github.io/sipru./](https://dantemorrigan.github.io/sipru/))**

---

## Что это

Sipru. — локальное веб-приложение для тех, кто пишет книги, рассказы и заметки. Всё хранится только на вашем устройстве. Никакой регистрации, никакого сервера, никаких подписок.

Построено на принципах iA Writer: одна колонка, выверенный шрифт, всё лишнее убрано.

## Возможности

### Письмо
- **Проекты и главы** — организуйте книги в проекты, главы перетаскиваются мышью
- **Заметки** — отдельный поток для идей, эпиграфов, черновиков
- **Богатое форматирование** — жирный, курсив, зачёркнутый, подчёркнутый, маркер, заголовки H1–H6, цитаты, списки (в том числе задачи), таблицы, блоки кода, изображения, сноски, разделители
- **Фокус-режим** — полноэкранный режим без интерфейса, выход по Esc
- **Автосохранение** — debounced через 500 мс после последнего нажатия, с гарантированным дописыванием при уходе со страницы, смене документа или режима и закрытии вкладки
- **Undo / Redo** — ⌘/Ctrl+Z, ⌘/Ctrl+Shift+Z, Ctrl+Y и кнопки в тулбаре; история живёт только в текущей сессии редактирования
- **Версии главы** — снимок текста в один клик: дата, число слов, превью, восстановление и удаление (хранятся последние 30, восстановление всегда сохраняет текущий текст отдельной версией)
- **Поиск** — ⌘/Ctrl+K по названиям глав, тексту и синопсису проекта, с подсветкой совпадения
- **Цели** — целевое число слов на проект, прогресс-бар и необязательная дневная норма

### Горячие клавиши
Работают на любой раскладке (в том числе кириллической) — привязка идёт к физической клавише. На macOS — ⌘, на Windows/Linux — Ctrl.

| Действие | Клавиши |
|---|---|
| Жирный / курсив / подчёркнутый | ⌘B · ⌘I · ⌘U |
| Зачёркнутый / маркер | ⌘⇧X · ⌘⇧H |
| Ссылка | ⌘K |
| Заголовки H1–H6 / обычный текст | ⌘⌥1…6 · ⌘⌥0 |
| Список нумерованный / маркированный / цитата | ⌘⇧7 · ⌘⇧8 · ⌘⇧9 |
| Выравнивание: влево · по центру · вправо · по ширине | ⌘⇧L · ⌘⇧E · ⌘⇧R · ⌘⇧J |
| Отменить / повторить | ⌘Z · ⌘⇧Z (и Ctrl+Y) |
| Сохранить | ⌘S |
| Разрыв страницы | ⌘⏎ |
| Сноска | ⌘⌥F |
| Фокус-режим / превью | ⌘⇧F · ⌘⌥P |
| Снять форматирование | ⌘\ |
| Отступ в списке | Tab · ⇧Tab |
| Поиск | ⌘K вне редактора |

### Шрифты прямо в редакторе
Шрифт переключается в тулбаре редактора — не нужно выходить в настройки. Три варианта:
- **Newsreader** — классическая книжная антиква
- **Spectral** — чистый, современный шрифт для статей
- **JetBrains Mono** — моноширинный для сценариев и технических текстов

### Превью, импорт и экспорт
- **Превью книги** — переключение между режимами "Редактор" и "Превью" прямо в шапке; превью показывает ровно тот же лист, что и редактор — формат, ориентация, поля, колонтитулы и разбивка на страницы совпадают
- **Экспорт** — гибкая настройка: выбор глав, шрифт, поля, нумерация страниц, оглавление, титульный лист
- **Форматы экспорта** — PDF (через печать), настоящий `.docx` (Office Open XML, без сервера и без зависимостей), TXT, Markdown
- **Импорт** — TXT, Markdown и HTML: новой заметкой с дашборда или новой главой в проект; HTML санируется до безопасного набора тегов

### Профиль
- **Аватар** — загрузите фото, оно автоматически обрезается до 400×400 px и отображается в шапке сайта
- **Имя** — задаётся при онбординге, редактируется в профиле
- **Тема** — светлая (тёплая бумага) или тёмная (ночное письмо)
- **Статистика** — слов написано, проектов, глав, заметок

### Данные
- **Локальное хранение** — всё на вашем устройстве, ничего не уходит на сервер
- **Хранилище (vault)** — вы выбираете обычную папку, и приложение раскладывает в неё
  проекты папками, а главы и заметки — отдельными `.md` файлами. Их видно в проводнике
  и можно открыть любым редактором; переустановка приложения их не трогает
- **Бэкап / восстановление** — экспорт всего в JSON и импорт обратно
- **Сброс** — возврат к состоянию по умолчанию с подтверждением

#### Как это устроено

`localStorage` — рабочая копия: в неё пишется каждое изменение, мгновенно. Папка
хранилища — то, что переживает всё остальное; в неё уходит debounced-запись после
каждого коммита в стор. Если запись в папку не удалась, приложение продолжает
работать на `localStorage`, так что сломанный диск не может стоить вам текста.

| | Десктоп (macOS / Windows) | Android |
|---|---|---|
| Выбор папки | системный диалог выбора папки | системный SAF-пикер (`ACTION_OPEN_DOCUMENT_TREE`) |
| Доступ к папке | путь + `tauri-plugin-persisted-scope` | persistable URI-грант, переживает перезагрузку |
| Разрешения | не нужны | **не нужны** — ни `MANAGE_EXTERNAL_STORAGE`, ни storage-permissions |
| Переживает переустановку | да | да — файлы остаются, папку нужно выбрать заново одним касанием |
| Показать в файлах | `revealItemInDir` | DocumentsUI через нативный мост |

На Android нет пути, до которого дотягивается файловый плагин Tauri и который был бы
одновременно видимым пользователю и долговечным: приватная папка приложения удаляется
вместе с ним, а прямая запись в `/storage/emulated/0/Documents` заблокирована scoped
storage при любых разрешениях. Поэтому Android работает через Storage Access Framework
— ровно та же модель, что на десктопе: пользователь один раз выдаёт папку, дальше
приложение пишет в неё обычные файлы. Нативная половина моста живёт в
`.github/scripts/android_vault.py` и вживляется в `MainActivity` при сборке.

## Технический стек

Никаких фреймворков и бандлеров: исходники — это восемь файлов с JSX, которые один короткий скрипт превращает в обычный браузерный JS.

| | |
|---|---|
| React 18.3.1 | production UMD, лежит локально в `vendor/` — без CDN |
| Сборка | `npm run build` → esbuild транспилирует `*.jsx` в `build/*.js` (без бандла, файлы остаются отдельными `<script>`) |
| Хранилище | `localStorage` — ключ `sipru:v1`, схема версионируется и мигрируется без потерь |
| Шрифты | Google Fonts, подключены неблокирующе; офлайн работают локальные фолбэки |
| Деплой | GitHub Actions (`npm ci && npm run build`) → GitHub Pages |

```bash
npm install      # один раз
npm run build    # после правки любого .jsx
npm run check    # проверить, что build/ соответствует исходникам
```

## Установка на macOS

Сборка `.app`/`.dmg` не подписана Apple Developer ID и не нотаризована (это платная программа Apple), поэтому при первом запуске Gatekeeper блокирует приложение с сообщением «файл повреждён» или «не удалось проверить наличие вредоносного ПО».

Открыть без терминала:

1. Не открывайте `.app` двойным кликом — вместо этого **правый клик (или Control+клик) → «Открыть»**.
2. В появившемся окне подтвердите **«Открыть»** ещё раз.

Это нужно сделать только один раз — при следующих запусках предупреждение не появится. `sudo xattr -rd com.apple.quarantine …` через терминал делает то же самое, но правый клик → «Открыть» — штатный путь macOS для неподписанных приложений, без терминала и `sudo`.

## Запуск локально

```bash
# из этой папки
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

> Открывать `index.html` напрямую через `file://` не получится — браузер блокирует загрузку модулей. Нужен HTTP-сервер.

```
sipru./
├── index.html              # Точка входа, подключает vendor/ и build/
├── app.jsx                 # Корень приложения, роутинг, сплеш, курсор

├── screens-editor.jsx      # Редактор с тулбаром, фокус-режимом, превью

```

## Деплой на GitHub Pages

Деплой настроен через GitHub Actions (`.github/workflows/deploy.yml`) и запускается автоматически при пуше в `main`.


Сайт (GitHub Pages) должен отдавать страницу с заголовком
`Access-Control-Allow-Origin`, иначе браузерная версия не сможет её
прочитать — в приложении (macOS/Android) запрос идёт из webview и CORS
не мешает.
